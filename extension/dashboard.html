Recovery and page captures

Pause takes effect after the current match operation. Closing the dashboard stops further matches. Only the resume position is stored. Reopen it and resume from the current list page. If interrupted in ThruLines, the extension returns to the saved list page first.

If a note editor is left open after an error, check it and close it before resuming. Existing notes are checked again, so an interrupted save is not blindly retried. Notes over 500 characters are skipped.

To report a changed layout, display that page in Ancestry, choose its tab above, and click Capture loaded page. The downloaded HTML includes names and notes; review it before sharing. Capture does not change any notes.
